# 阅词（YueCi）

一款面向英语学习者的桌面工具，用于自动获取 News in Levels 文章并生成适合阅读与背诵的 Word 学习文档。

## 项目简介

阅词旨在帮助英语学习者更高效地利用 News in Levels 网站的英语阅读资源。

软件可以自动获取最新文章，整理阅读内容，并生成 Word 文档，方便打印、保存和后续学习。

## 主要功能

* 自动获取 News in Levels 最新文章
* 支持不同难度等级文章
* 自动生成 Word 学习文档
* 支持中文 / English 双语言界面

## 使用方法

1. 下载 Release 页面中的最新版本
2. 解压压缩包到任意文件夹
3. 双击运行「阅词.exe」
4. 获取文章列表
5. 选择文章并生成 Word 文档

## 系统要求

* Windows 10
* Windows 11

## 发布版本

当前版本：v1.0


## 开发说明

本项目基于 Python 开发，使用 PyInstaller 打包为 Windows 桌面程序。

# YueCi

A desktop application designed for English learners to automatically fetch News in Levels articles and generate Word study documents.

## Overview

YueCi helps English learners make better use of News in Levels resources by automatically collecting articles and generating well-organized Word documents for reading, review, and printing.

## Features

* Fetch latest News in Levels articles
* Generate Word study documents automatically
* Chinese and English user interface

## How to Use

1. Download the latest release
2. Extract the package
3. Launch YueCi.exe
4. Fetch articles
5. Generate Word documents

## System Requirements

* Windows 10
* Windows 11

## Current Version：v1.0


## Development

Built with Python and packaged using PyInstaller.
